Autocomplete & pickers

Async-feeling typeahead search with keyboard navigation, the native datalist element, a tag input that builds a list of values, and a native date picker.

Typeahead search async-feeling

Suggestions are filtered after a simulated 300ms network delay and support full keyboard navigation (↑/↓ to move, Enter to select, Esc to close).

    Selected: none

    Native <datalist>

    Browser-native autocomplete backed by an <input list> — rendering is handled entirely by the OS/browser, not the page.

    Tag input multi-value

    Type a value and press Enter or , to add a tag; click the × to remove one.
