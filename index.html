A sandbox built to be automated

Eleven small modules, each isolating one class of UI behavior — inputs, tables, frames, dialogs, timing, drag-and-drop, and deliberately tricky locators. Point Playwright, Selenium, or Robot Framework at it and practice writing resilient locators and assertions against real edge cases, not idealized markup.

How this is organized

Every control on every page carries a data-testid where a real app would have one — and several controls deliberately omit them, duplicate them, or hide them, so you get practice writing locators by role, text, and structure instead of only by test id. Badges next to each control call out exactly what edge case it demonstrates.

Running it

This is a static site — no build step, no backend. Open index.html directly in a browser, or serve the folder locally (npx serve . or Python's python -m http.server) and point your automation base URL at it. Every interactive element is native HTML wherever possible, so the same locators you'd use against a real product apply here.

Built for practicing Playwright, Selenium, and Robot Framework locators.
